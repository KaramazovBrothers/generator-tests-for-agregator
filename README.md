# Generator tests for aggregator

Генератор депозитных тестов для агрегаторов: HPP/H2H, COM и PINCO/WL,
региональная матрица браузеров, минимальный и максимальный наборы.
Интерфейс и кейсы доступны на RU, EN и UKR.

## Исходники

- `src/generator.html` — актуальный HTML-макрос, стили, логика и переводы.
- `scripts/build.py` — сборка страницы предпросмотра и текста макроса.

Начальная версия основана на согласованной v18. В дальнейшем история изменений
хранится в Git; создавать отдельные файлы v19, v20 и т. д. не нужно.
Скриншоты инструкции встроены в HTML. Генератор не сохраняет введённые данные.

## Сборка

Требуется Python 3. Дополнительные зависимости не нужны.

```sh
python3 scripts/build.py
```

Откройте `dist/preview.html` в браузере. Для Confluence скопируйте **весь текст**
`dist/confluence.txt` в тело макроса HTML, заменив предыдущий код.
Сборка не публикует и не изменяет страницу Confluence автоматически.

## Проверка изменений

Проверьте HPP/H2H, минимальный/максимальный набор, COM/PINCO, изменение суммы,
обязательный чек, QR/OneClick, таймер и отмену. Для COM проверьте отдельного
USD-пользователя. В полном наборе COM/PINCO должны быть нативное приложение и
WebView. Для Канады должен присутствовать Samsung Internet.

Проверьте RU/EN/UKR, сохранение введённых значений при смене языка, копирование
одного кейса и всего набора, раскрытие инструкций и увеличение изображений.
После локальной проверки отдельно проверьте HTML-макрос в Confluence.

Не добавляйте реальные пароли, токены, заполненные тестовые формы и выгрузки Jira
в репозиторий. Данные аккаунтов вводятся пользователем при работе с генератором.
